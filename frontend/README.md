# FastFoody — frontend

React 19 + Vite + Tailwind CSS v4 + shadcn/ui asosidagi SPA. Backend bilan faqat REST API
orqali ishlaydi (`VITE_API_URL`).

```bash
npm install
cp .env.example .env
npm run dev      # http://localhost:5173
npm run build    # tsc -b && vite build
npm run lint
```
